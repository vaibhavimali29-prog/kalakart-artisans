# KalaKart: Your Artisan Market

Build a beautiful, modern, aesthetic and production-quality Lovable mobile application named:

"KalaKart"

Tagline:

"Empowering Artisans, Connecting Traditions"

The application is an AI-powered digital marketplace and smart cataloging assistant designed for marginalized artisans. The UI should be inspired by the attached food-delivery app reference image: premium, warm, rounded, clean, card-based, visually rich and highly polished.

IMPORTANT:

Do NOT copy the food app literally.

Use its visual quality, spacing, card layout, rounded corners, typography hierarchy and premium mobile-app feel as inspiration, but completely redesign it around Indian handicrafts, artisans and traditional products.

--------------------------------------------------

1. OVERALL DESIGN LANGUAGE

--------------------------------------------------

Create a premium Indian handicraft aesthetic.

Use a warm artistic color palette:

- Terracotta / burnt orange

- Deep maroon

- Cream / ivory

- Warm beige

- Subtle golden accents

- Dark brown text

The interface should feel:

- Elegant

- Warm

- Cultural

- Modern

- Trustworthy

- Minimal

- Easy to understand

- Not overcrowded

Use:

- Large rounded cards

- Soft shadows

- Subtle gradients

- Large product imagery

- Smooth animations

- Proper whitespace

- Rounded buttons

- Clear typography

- Consistent iconography

Avoid:

- Excessive text

- Complicated menus

- Too many icons

- Clutter

- Very bright colors

- Tiny buttons

- Complex navigation

The app must be comfortable for users who may have limited digital literacy.

--------------------------------------------------

2. BOTTOM NAVIGATION

--------------------------------------------------

IMPORTANT:

There must be ONLY 3 permanent tabs at the bottom.

1. Products

2. Your Orders

3. Inquiry

Do NOT create 5 tabs.

Do NOT create Home, Menu, Rewards or Profile tabs.

Use a modern floating/rounded bottom navigation bar.

Icons:

Products → shopping bag / storefront icon

Your Orders → receipt / package icon

Inquiry → chat bubble icon

The currently selected tab should have a prominent filled circular/rounded background and clear label.

--------------------------------------------------

23. VISUAL QUALITY

--------------------------------------------------

The final application should feel like a premium startup product.

Reference qualities:

- Modern food delivery app aesthetics

- Premium e-commerce design

- Indian cultural visual identity

- Minimal UI

- Large beautiful imagery

- Rounded cards

- Soft shadows

- Strong typography hierarchy

- Warm colors

- Excellent spacing

Do not make it look like a basic college project.

It should look like a real startup product that could be demonstrated to SIH judges.

Most importantly:

KalaKart should visually communicate:

"An artisan speaks or uploads a photo → AI understands the craft → AI creates a professional listing → AI suggests the price → artisan can sell digitally."

Make the interface intuitive enough that an artisan can understand the main workflow without reading a manual.
